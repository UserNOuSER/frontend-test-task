# frontend-test-task

## Как запустить

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Если в PowerShell блокируется запуск сценариев, выполните:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
npm run dev -- --host 0.0.0.0
```

После запуска откройте локальный адрес из вывода терминала, обычно это http://localhost:5173
